floodFill(grid, x, y, colorTarget, newColor) → {Array.<Array.<number>>}

The Flood fill performs operations on a 2D grid beginning with (x,y) coordinates. Does the changes of all connected same-color cells to new colors and returns the number of cells changed, using Depth-First Search (DFS). Returns 0 in case if the new color matches the original one.
Parameters:
Name Type Description
grid Array.<Array.<(number|string)>> element represntation of a color with 2D array.
x number The initial column index (x-coordinate).
y number The initial row index (y-coordinate).
colorTarget number The color value we want to replace
newColor number | string The new color value to replacee the original region with.

 const grid = [
    [1, 1, 0],
    [1, 0, 1],  
    [0, 1, 1]  
 ];
// Calling floodFill(grid, 0, 0, 2) does the change of the
region of 1s starting at (0,0) to 2 and returns the count of cells 3.
// usage demonstation
const changedCount = floodFill(grid, 0, 0, 2);
console.log(changedCount); The return: 3
