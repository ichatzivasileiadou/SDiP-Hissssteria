manhattan_distance(gameState) → {Object|null}

Calculates the manhattan distance between snake's head and each food, Finds the minimum manhattan distance and return the food that is in the minimum distance.

Parameters:
Name Type Description
gameState Object

Game state current object
game.you Object

Details of our snake
Array.<{x: number, y:number}>

Coorditates of snakes body - gameState.you.body
Returns:
  • Either closest food object or null if no food id found
Type
Object | null
Example
Returns the closest food to the snake's head using Manhattan distance:
const gameState = {
 you: {body: [{x:0 , y:0}] },
 board: {food: [{x:1 , y:1}, {x:5 , y:5}] }
});
// Return: {x:1 , y:1}

GameState

Checks if my snake is close with other snakes, and if it is, we check that our length is bigger than them. Returns true if there is no snake nearby, and if there is if our snakes length is bigger that the enemys length. Returns false if there is a snake nearby and their length is >= than our snake.
